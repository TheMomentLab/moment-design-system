# MomentMark

Geometry is supplied in Moment Lab.zip: a single-color arc, arm, off-axis mass and pivot. Preserve the geometry; do not substitute an icon or rotate it. Default size 48px; brand use minimum 16px; <=24px uses the supplied thicker stroke and larger masses. `color` accepts the intended foreground; default is --ml-brand. `title` names standalone marks. Use `decorative` inside Lockup or beside equivalent visible identity. See docs/moment/implementation.md and the original asset inventory for provenance.
